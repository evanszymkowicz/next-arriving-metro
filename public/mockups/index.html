UI Mockups

Three production directions for Next Arriving Metro — same grid, different aesthetics

Mockup 01
PIDS
WMATA PIDS-inspired display. Serif station name, M-metro logo, light beige palette, small 2-piece status banner, clock with seconds.
 Mockup 02
Poster
Bold condensed typography, thick black rules, white panels, large orange full-width advisory banner. No logo.
 Mockup 03
Flip Board
Mechanical flip-board aesthetic. Amber color, Archivo + DM Mono fonts, analog clock, flap indicators, 2-piece status banner.

All mockups share a 2-panel grid (trains + buses) with full-width advisory banner. All have light + dark mode via the toggle. They use static mock data and are self-contained HTML files served from /mockups/.
